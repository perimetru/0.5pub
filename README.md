# 0.5 PUB — меню

Адаптивное меню на русском, румынском и английском языках. Названия, цены в MDL и единицы взяты из резервной копии RestoFlow. Показаны активные позиции в активных категориях. Фотографии, состав блюд и контакты не придуманы.

## Запуск

Из `/workspace/0.5pub`:

```sh
python3 -m http.server 8080 --bind 0.0.0.0 --directory site
```

Сервер должен раздавать **только `site/`**. Исходная резервная копия содержит внутренние данные и не должна входить в публикацию сайта.

## Обновление меню

```sh
python3 tools/import_menu.py restoflow-manual-2026-10-12-14-54-51.json
```

Для новой резервной копии передайте путь к новому файлу. Экспорт включает только публичные поля меню. Исходный файл не меняется. Один некорректно закодированный размер `0,5 Р»` отображается как `0,5 л`.

## Публикация

Сайт не требует сборки и внешних сервисов. На статический хостинг загрузите содержимое `site/`: `index.html`, `styles.css`, `app.js`, `menu.json`. Публикация сайта выполняется отдельно от публикации облачной среды.

## Английские переводы

Переводы 151 позиции и 16 категорий хранятся в `tools/menu_en.json` по стабильным ID. Импорт сохраняет их в публичном `site/menu.json`. При добавлении новой позиции импорт попросит добавить её английский перевод, чтобы меню оставалось полностью переведённым. Названия брендов сохранены; цены и объёмы не меняются.

## Макет паба

Первый экран использует рабочий девиз: «За добрую компанию, сытный стол и здоровье королевы!». Далее идут три позиции разливного пива с реальными ценами, полное меню, атмосфера паба, символы (Баба-яга из Праги и королева) и ссылка на Facebook. Все тексты доступны на RU, RO и EN. Категории раскрываются нажатием; поиск открывает найденные категории автоматически.

Настоящие фотографии предоставлены в чате как визуальные ориентиры, но ещё не доступны в файловой системе. Фотогалерея пока не включена; для добавления нужны оригинальные JPG/PNG. В шапке размещены подтверждённые владельцем телефон резервации 079 070 505 и адрес Cahul, Str. Mihai Viteazul 37. Номер открывает звонок; адрес открывает автомобильный маршрут в Google Maps. Часы работы пока не указаны.

## Характеристики пива

Поля алкоголь (% об.), начальная плотность (°P), горечь (IBU), цвет и мутность хранятся в `tools/beer_profiles.json` и сохраняются при импорте меню. Числовые значения пока `null`, цвет и мутность — объекты с ключами `ru`, `ro`, `en`. Неизвестные значения отображаются как прочерки с пометкой об уточнении; не выводятся из названий сортов.

## Просмотр на компьютере

В папке `downloads/` находятся `05-PUB.html` (сайт в одном файле, не требует сервера) и `05-PUB-site.zip` (тот же файл в архиве). Скачайте HTML и откройте в Chrome или Edge; либо распакуйте ZIP и откройте `05-PUB.html`. Меню, логотипы, стили и тексты встроены в файл. Телефон, Google Maps и Facebook открывают внешние приложения или сайты.

Меню разделено на «Бар» и «Кухня» по полю `route` исходных категорий RestoFlow. Каждый раздел показывает только свои категории и позиции. Поиск работает в выбранном разделе; при переключении раздела запрос сохраняется, а фильтр категории сбрасывается. Все 151 позиции сохранены.
