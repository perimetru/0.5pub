# Логотипы паба

`05PUB-logo.eps` — оригинал, предоставленный владельцем.

Браузерные векторные версии находятся в `site/assets/`:

- `05pub-horizontal.svg` — 0.5 PUB Craft Beer; используется на сайте.
- `05pub-stacked.svg` — компактный 0.5 PUB.
- `albeer.svg` — надпись Albeer.
- `logos.svg` — все три варианта на исходном листе.
- `05pub-logo.png` — растровая версия исходного листа с прозрачным фоном.

SVG получены из EPS через Ghostscript (PDF) и pdftocairo (SVG); отдельные версии используют области исходного листа. Рисунок логотипов сохранён.
